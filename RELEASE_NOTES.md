# MorphVerse v1.0

1,000 source-matched building groups, each with Manhattan, curved, oblique and mixed variants, for 4,000 furnished floor plans and corresponding MuJoCo scenes.

The archive includes metric floor-plan geometry, furniture identities and poses, native scene XML, shared meshes and textures, source annotations and floor-plan previews. Source-scene identities and file hashes accompany the data.

Extract `morphverse-v1.0.tar.xz` into the repository directory. Component licenses and attribution are included in the archive.
